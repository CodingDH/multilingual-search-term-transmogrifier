Search Relevance Reviewer

Review productive terms and representative GitHub results.
Review two questions separately. “Term assessment” concerns the proposed translation; “retrieval assessment” concerns what GitHub returned. Initial selections marked Codex provisional are conservative suggestions, not completed review. Changing either assessment marks that row as human reviewed. Downstream handling is derived automatically: credible + relevant terms are Retained, suspect + irrelevant terms are Excluded, and every mixed combination is Retained + tracked for relevance.
Run python scripts/exploration/build_search_relevance_review.py, then load search_result_relevance_review.csv.
