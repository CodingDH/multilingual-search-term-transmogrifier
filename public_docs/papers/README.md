# Publication Artifact Guides

The papers in this directory use the same underlying language metadata and candidate-term corpus but ask different research questions. Keeping their artifact maps separate avoids freezing the whole repository around one publication.

| Guide | Main question | Repository emphasis |
| --- | --- | --- |
| [Translation to Transmogrification](translation-to-transmogrification/README.md) | What does responsible exploration of LLM-generated multilingual metadata require? | Language infrastructure, visible and latent failures, prompt sensitivity, exact disagreement, rationale rhetoric, and GitHub retrieval |
| [Multilingual translation embeddings](multilingual-translation-embeddings/README.md) | What structures emerge when multilingual candidates and rationales are compared geometrically? | Embeddings, dispersion, centroids and medoids, neighborhood stability, prompt/model variation, and cross-term comparison |

Artifact guides should record the relevant release tag once a paper is submitted or published. Development work may continue on the default branch without changing a paper's documented snapshot.
