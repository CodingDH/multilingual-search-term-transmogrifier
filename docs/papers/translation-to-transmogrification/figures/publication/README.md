# Publication Figures and Tables

This directory contains the figures and tables selected for *From Translation
to Transmogrification*. Files are numbered in article order: `figure01.png`
corresponds to Figure 1, and `table01.png` corresponds to Table 1. The
inventories below provide the full caption, accessibility-focused alt text,
source notebook, and production status for each file.

Most PNGs omit an embedded title and subtitle because that information appears
in the caption. Matching SVG files are retained when a composite or pipeline
diagram has an editable vector source. Notebook-generated source figures,
exploratory charts, and titleless intermediates are available in the adjacent
[`../analysis/`](../analysis/) directory. Shared diagrams used across the
project remain in the repository-level [`figures/`](../../../../../figures/)
directory.

## Reading the Inventories

- **Order** gives the number used in the article.
- **Current figure title or source filename** identifies the corresponding file
  in this directory.
- **Caption** contains methodological context and the principal reported
  result. It also preserves titles and subtitles removed from the image.
- **Alt text** describes the visual form and the most important visible
  patterns without requiring access to the image.
- **Status** records the source notebook or script and any relevant production
  decisions.
- **Location** confirms that the numbered export belongs to this publication
  directory.

The figures summarize generated outputs, review decisions, and analytical
comparisons. Coverage, agreement, expected-script conformity, and classifier
performance should not be interpreted as independent validation of linguistic
accuracy.
